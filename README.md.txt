
                                                                     --------Campus Life------- 


Bienvenue sur le dépôt de mon tout premier brief chez YouCode ! Ce projet s'appelle Campus Life, un site web pour aider les nouveaux apprenants à découvrir l'univers de l'école.

-> Description

Dans ce projet, j'ai appris à transformer une maquette Figma en un vrai site web avec HTML et CSS. L'objectif était de créer un site simple, propre et facile à utiliser.

->  Les pages du site

Accueil (Accueil.html) : La page principale qui présente l'ambiance de Campus Life.

Campus (campus.html) : Une page pour découvrir les différents campus YouCode.

Inscription (inscription.html) : Un formulaire pour les personnes qui veulent nous rejoindre.

->  Ce que j'ai utilisé

HTML5 : Pour construire la structure des pages avec des balises sémantiques.

CSS3 : Pour ajouter le style, les couleurs, et organiser les éléments avec Flexbox et CSS display.

Git & GitHub : Pour enregistrer l'avancement de mon travail et héberger le code.

Figma : Pour suivre le design original du projet.
